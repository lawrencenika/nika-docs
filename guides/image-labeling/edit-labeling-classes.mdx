title: "Edit Labeling Classes"
description: "Learn how to add, edit, and manage labeling classes for your annotation jobs"
---

Learn how to manage labeling classes in your annotation jobs, including adding new classes, editing existing ones, and protecting classes from accidental changes.

## Step 1: Add a New Class

Use the bottom of the labeler right panel to add new class entries.

![Add New Class](/guides/image-labeling/edit-labeling-classes-1.jpg)

When adding a class, you can specify:
- **Class Name**: The name of the annotation class
- **Super Class** (optional): Used to group classes of the same family together for certain model training purposes

## Step 2: Edit or Remove a Class

Once a class is created, you have options to manage it.

![Edit or Remove Class](/guides/image-labeling/edit-labeling-classes-2.jpg)

For each class, you can:
- **Edit**: Click the edit button to enter edit mode
- **Remove**: Click the trash button to remove this class

**Note**: Removing a class will also remove all associated annotations with this class.

## Step 3: Modify Class Properties

When in edit mode, you can modify various properties of the class.

![Edit Class Properties](/guides/image-labeling/edit-labeling-classes-3.jpg)

You can modify:
- **Class Name**: Change the name of the class
- **Super Class Name**: Update or add a super class grouping
- **Class Color**: Adjust the color used to display this class in annotations

After making changes:
- Click the **✓** (tick emoji) to save your changes
- Click the **✕** (cross emoji) to cancel changes

## Step 4: View Associated Annotations

Each class displays the number of annotations associated with it.

![View Annotation Count](/guides/image-labeling/edit-labeling-classes-4.jpg)

This helps you track which classes are being used and how extensively they've been annotated.

## Step 5: Lock Classes to Prevent Changes

Users of the workspace can click the lock button to lock/unlock class edits to protect against mistaken changes.

![Lock Classes](/guides/image-labeling/edit-labeling-classes-6.jpg)

When classes are locked:
- Other users cannot make edits to existing classes
- Other users cannot remove existing classes in this job
- This protects your class structure from accidental modifications

Happy labeling!
