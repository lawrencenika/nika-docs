---
title: "Download Files and Folders"
description: "Learn how to download files and folders from your workspace's file storage"
---

You can download individual files, multiple files, or entire folders from the File Storage panel.

## Download Files

1. **Select files**: Click a file to select it, or hold **Cmd** (Mac) / **Ctrl** (Windows) and click to select multiple files
2. **Right-click**: Right-click on any of the selected files
3. **Click "Download"**: Choose "Download" from the context menu

Each selected file will be downloaded individually to your computer.

![Download Files](/guides/manage-file-lake-per-workspace/download-files.jpg)

## Download a Folder

1. **Right-click** on the folder you want to download
2. **Click "Download"**: Choose "Download" from the context menu

The folder and all its contents will be automatically zipped and downloaded as a `.zip` file.

![Download Folder](/guides/manage-file-lake-per-workspace/download-folder.jpg)

<Note>
  Very large folders may take too long to zip on the server and the download could fail. If this happens, you can either download files inside the folder individually, or contact our data migration team for assistance with large exports — [book a call](https://cal.com/lawrence-nika/export-20-gb-files-from-nika.eco) or email [support@nikaplanet.com](mailto:support@nikaplanet.com).
</Note>
