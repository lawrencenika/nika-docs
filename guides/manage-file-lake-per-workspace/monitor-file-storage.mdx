NikaPlanet provides several ways to monitor how much file storage your team is using.

## Check Storage in a Workspace

At the bottom of the File Storage panel in any workspace, you can see the total storage available for your organization.

![Workspace Storage Indicator](/guides/manage-file-lake-per-workspace/file-storage-monitoring-1.jpg)

## Check Storage Across All Workspaces

For a detailed breakdown of storage usage across all workspaces under your team:

1. Go to **Settings** → **Usage** ([planet.nika.eco/en/settings/usage](https://planet.nika.eco/en/settings/usage))
2. Select the correct team from the team switcher on the left sidebar
3. Click the **Storage** tab

![Select Team in Settings](/guides/manage-file-lake-per-workspace/select-team-in-settings.jpg)

This view shows storage used per workspace, including object counts, storage size, and percentage distribution.

![Team Storage Usage Details](/guides/manage-file-lake-per-workspace/file-storage-monitoring-2.jpg)

## Check Your Current Plan

To see the storage quota included in your current plan:

1. Go to **Settings** → **Billing** ([planet.nika.eco/en/settings/billing](https://planet.nika.eco/en/settings/billing))
2. Select the correct team from the team switcher on the left sidebar
3. Review the **Storage** line item showing your plan's total allocation

![Billing Plan Storage](/guides/manage-file-lake-per-workspace/file-storage-monitoring-3.jpg)
