---
title: "Organize Files and Folders"
description: "Learn how to move and organize files and folders within your workspace's file storage"
---

After uploading your data, you can reorganize files and folders by moving them between directories. There are two ways to move items in the File Storage panel.

## Method 1: Move via Right-Click Menu

1. **Select Items**: Hold **Cmd** (Mac) or **Ctrl** (Windows) and click each file or folder you want to move
2. **Right-Click**: Right-click on any of the selected items
3. **Choose "Move"**: Select "Move" from the context menu
4. **Pick Destination**: Choose which subfolder or the root `/data/` folder to move them into

![Move via Right-Click Menu](/guides/manage-file-lake-per-workspace/move-files-by-select.jpg)

## Method 2: Drag and Drop

1. **Select Items**: Hold **Cmd** (Mac) or **Ctrl** (Windows) and click to select one or more files or folders
2. **Drag**: Click and drag the selected items
3. **Drop onto Folder**: Drop them onto any existing folder at the same level in the file list

![Drag and Drop to Move](/guides/manage-file-lake-per-workspace/move-files-by-drop.jpg)

A progress status bar will appear to track the move operation.
