## Overview

NikaFunction is a powerful serverless function platform that enables you to deploy Python scripts as geosptial serverless functions with one click, and you can leverage AI agents to modify the code.

![NikaFunction Interface](/products/nika-function.jpg)

## Key Features

### Simple Geospatial Library Configuration 
- **GDAL support**: simply add gdal==="*" to choose the latest version of GDAL for your script to depend on
- **Confa-forge/Pypi support**: simply add any other python library with version id to be installed directly
- **CUDA support**: GPU VM options will already come with compatible CUDA pre-installed for your PyTorch script to use

### Flexible Compute Options
- **High RAM CPUs**: choose the high RAM CPU options for RAM-heavy geospatial processing needs
- **Various GPUs**: now comes with NVIDIA T4 with multiple options at your choice, or you can request for more intensive ones such as H100 from Nika
- **Pay-Per-Use**: only pay for actual function execution hours

### Integration Capabilities
- **NikaWorkspace**: once deployed successfully, it appears as button click option in your list of function that only your team can use 
- **NikaFlow**: used as a node option inside NikaFlow, the ETL prodcut of Nika (to be integrated)
- **NikaAPI**: deployed as an API for your other features or product to make direct API call to (to be built)
